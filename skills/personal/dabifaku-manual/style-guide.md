# 文体ガイド — 影山優佳さん風(ファンによる文体模写)

取説の全文をこの文体で書く。現行原稿(`note-article/chapters/`)が最良の見本なので、書く前に必ず2〜3章読んで温度感を取り込むこと。

## 語りの土台

- **です・ます調**の敬体。一人称は「私」、読者には「皆さん」と呼びかける
- 頭の良さが「整理力」として出るタイプ。長い説明は必ず章立て・箇条書き・手順に構造化して、そのうえで語り口は柔らかく
- 専門用語(ニトロ、クロス、インブリード、PWA など)は初出時に必ず一言で言い換える。読者を置いていかない
- 読者を安心させるフレーズを適所に(「安心してくださいね」「探さなくて大丈夫」「慌てずに」)

## 署名的な癖(これがないと別人になる)

1. **サッカー比喩**: 配合検討を監督の采配にたとえるのが軸。布陣/4-4-2/スタメン/選手交代/ロッカールーム/ハーフタイム/アディショナルタイム/下部組織/クラブ運営 など。
   - 頻度は**1章に1〜2回まで**。三連発すると文体模写ではなくギャグになる
2. **「……」の溜め**からの本音・独白(「……これ、頭の中だけで組み立てるのは正直かなり大変で。」)
3. **自己ツッコミ+(笑)**: 熱量を出した直後に一歩引いて笑う
   - 例:「優勝する気しかないので。」「ネーミングセンスは見逃してください。」「私も作業枠、もう少し増やしてきます(笑)。」
4. **熱量の吐露**: 好きなものへの気持ちを素直に言う(「たまりません」「涙が出ます」「これが本当にありがたい……!」)
5. **体言止めの短文**で余韻を作る(「キックオフ前の静けさ。」「まさに采配の見せどころです。」)
6. 「!」は要所だけ。多用しない。感嘆の最上級は「──」や「……!」で溜めてから

## 章の型

1. リード1〜2文(この章で何ができるようになるか、比喩を添えて)
2. スクショ → 操作手順(番号つきや太字のUI名で)
3. 補足・注意(「監督としての注意事項です」のような前置きで深刻になりすぎない)
4. 軽いオチか次章への引き(「第7章で!」)

UI 上の文言・ボタン名は **太字** で正確に引用する(「＋ カテゴリを追加」「配合を保存」)。実装と一字一句合わせること。

## やらないこと

- ギャル語・若者言葉・絵文字・顔文字(「(笑)」だけは可)
- 上から目線、命令口調(「〜してください」は可、「〜すべき」は不可)
- 仕様書口調の直訳(「〜が可能です」「〜となっております」)→「〜できます」「〜です」に開く
- 比喩の乱発、同じ比喩の使い回し
- 誇張した萌え語り。熱量は「考えることが好き」の方向で出す
- 実在の人物・団体への言及の追加(サッカー一般の語彙に留め、特定チーム・選手名は出さない)
